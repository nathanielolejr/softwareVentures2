## How we build

Every project starts with a small, typed core. Here is a tiny example of validating a contact form with Zod:

```ts
import { z } from "zod";

const schema = z.object({
  email: z.string().email(),
  message: z.string().min(10),
});

export function parse(input: unknown) {
  return schema.safeParse(input);
}
```
